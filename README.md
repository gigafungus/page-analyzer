## [Пример работы приложения на сервисе render.com](https://flask-page-analyzer.onrender.com)

>## Использование
>### Приложение предназначено для ручной проверки сайтов на SEO-пригодность.
> Вы вводите интересующий вас URL в пустую строку.
> Его корневая часть сохраняется, если введена корректно, в противном случае появится сообщение об ошибке.
> 
> Теперь можете проверить доступность сайта и при успешной проверке увидеть:
> - Код ответа от обслуживающего сайт сервера
> - Название сайта
> - Описание сайта
> - Первый заголовок сайта
> - Идентификатор и дата сделанной проверки
>
> Все успешные проверки сохраняются для каждого адреса отдельно, но их нумерация общая.
> 
> Если проверка не удалась, возможны следующие причины:
> - Сервер вернул код ответа 4xx или 5xx
> - Введенный URL не обслуживается 
> - Неверно указан протокол работы сайта (https/http)
> - Превышен тайм-аут запроса
> - Проблемы с сертификатом сайта
> - Сервер не принимает подключения

## Установка

```bash
git clone https://github.com/gigafungus/page-analyzer.git
cd page-analyzer
# создайте файл .env
# укажите в нем переменные окружения SECRET_KEY и DATABASE_URL
# подробнее о переменных см. файл .env.example
make setup
make dbsetup
```

## Запуск

Для запуска в режиме разработчика используйте первую команду, а вторую введите во втором окне терминала:
```bash
make dev
make watch
```
и откройте [эту ссылку](http://127.0.0.1:5000/) в вашем браузере


Для запуска в режиме пользователя просто введите

```bash
make start
```
и откройте [эту ссылку](http://localhost:8000/) в вашем браузере
